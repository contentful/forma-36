Toggle a contextual option or view on or off, such as setting text to bold or
italic. Use `Button` for actions that change system state and `Switch` for
persistent settings.

## Import

```js static=true
import { ToggleButton } from '@contentful/f36-components';
// or
import { ToggleButton } from '@contentful/f36-button';
```

### Icon only

Toggle buttons can display only an icon in the `tiny`, `small`, and `medium`
sizes. Always provide an `aria-label` that describes the toggled state or
action when no visible label is present.

```jsx file=../../examples/ToggleButtonIconOnlyExample.tsx

```

### Transparent

Use the `transparent` variant for toggles inside rows, toolbars and other dense
surfaces where a bordered button would compete with the content, for example a
button that opens a settings popover. When active, it shows a blue background
and a primary-colored icon instead of a border.

```jsx file=../../examples/ToggleButtonTransparentExample.tsx

```
