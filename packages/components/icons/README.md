# @contentful/f36-icons

## Play icon

`PlayIcon` supports `medium` (20px), `small` (16px), and `tiny` (14px) sizes.
Use `isActive` for the duotone variant. The icon inherits the current text color;
use `color` to override it.

```tsx
import { PlayIcon } from '@contentful/f36-icons';

<PlayIcon size="small" />;
<PlayIcon size="small" isActive />;
```
